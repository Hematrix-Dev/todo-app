# 📝 Todo App

A simple and modern Todo App built with React Native and Expo to help users organize and manage their daily tasks.

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📅 Add date and time
- 🏷️ Task categories
- 🔥 Task priorities
- 🔎 Search tasks
- 📌 Filter tasks by All, Today, Active and Completed
- 📊 Task completion progress
- 💾 Local task storage
- 📱 Android APK
